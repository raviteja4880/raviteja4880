## Featured Projects

### RAG Premium v3.0 — Production-Grade AI Retrieval System

**Impact:** Enterprise-scale document retrieval system enabling sub-second latency question answering with 95%+ accuracy across multi-million document corpus.

**Engineering Highlights:**
- **Dual-LLM Pipeline Architecture:** Dual language model inference layer for response quality optimization
- **Advanced Reranking:** Integrated FlashRank reranking for precision retrieval accuracy
- **High-Performance Caching:** Redis-backed caching layer reducing query latency by 70%
- **Modular Pipeline Design:** Fully decoupled ingestion, retrieval, and generation stages enabling independent scaling
- **Production-Ready Streaming:** Server-Sent Events (SSE) implementation for real-time response streaming

**Tech Stack:** FastAPI • React • Pinecone Vector DB • MongoDB • Redis • PyMuPDF • RapidOCR • Groq LLMs (Llama 70B & 8B) • FlashRank

**Workflow:** Upload → Extract → Chunk → Embed → Retrieve → Rerank → Generate → Stream → Store

**Repository:** [github.com/raviteja4880/RAG](https://github.com/raviteja4880/RAG)

### Guardian SOS App — Mission-Critical Android Safety Platform

**Impact:** Mission-critical safety application enabling real-time emergency response with deterministic GPS tracking and automated alert distribution.

**Engineering Highlights:**
- **Deterministic SOS Detection:** Multi-sensor shake detection algorithm triggering alerts within milliseconds
- **Real-Time Location Tracking:** Fused location provider with high-accuracy GPS coordinates pushed to Firestore
- **Automated Alert System:** Parallel SMS and push notification delivery to emergency contacts via SmsManager
- **Clean Architecture:** MVVM pattern with LiveData, ViewModel, and Navigation Components for maintainability
- **Geolocation Services:** Custom geocoding implementation for human-readable address generation
- **Background Operations:** Robust background service handling ensuring reliability during low-battery scenarios

**Tech Stack:** Java (Android) • Firebase Firestore • Google Maps SDK • Android Sensors • Fused Location Provider

**Architecture Highlights:** Clean Architecture with MVVM, LiveData, and reactive data flow
